# 🚀 Job Scheduling System

A web-based **Job Scheduling System** that efficiently manages and prioritizes tasks using **priority queues (Min-Heap & Max-Heap)** in **C++**. The frontend is built using **HTML & CSS**, providing an interactive UI for job management.

---

## 📌 Features
✅ **Priority-Based Scheduling** - Uses **Min-Heap & Max-Heap** for optimized job execution.  
✅ **Job Management System** - Users can **add, remove, and modify** jobs dynamically.  
✅ **Efficient Execution** - Ensures the **highest priority job is executed first**.  
✅ **Interactive UI** - Simple **web interface** for managing and displaying jobs.  
✅ **Dynamic Execution** - Users can **add jobs, see pending jobs, and execute them**.  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS  
- **Backend:** C++ (Heap-based priority queue)  
- **Data Structures Used:** Min-Heap & Max-Heap (Priority Queue)
